### Terraform Azure Infrastructure Automation | GitHub

* Developed a Terraform-based Infrastructure as Code (IaC) project for provisioning and managing Microsoft Azure infrastructure using reusable Terraform modules.
* Implemented Azure infrastructure components including Virtual Networks, Subnets, NSGs, AKS, ACR, Application Gateway, WAF, Storage Accounts, Key Vault, Private Endpoints and monitoring components.
* Configured Azure Storage for Terraform remote state management and state locking to support consistent infrastructure deployments.
* Integrated Terraform workflows with Azure DevOps YAML pipelines for infrastructure initialization, validation, planning and deployment.
* Used Terraform variables, locals, outputs and reusable modules to improve infrastructure consistency and maintainability.
* Applied Azure security and networking practices including RBAC, NSGs, Private Endpoints and WAF.
* Maintained the infrastructure code using Git/GitHub with version-controlled Terraform configurations.

**Technologies:** Terraform, Microsoft Azure, Azure DevOps, AKS, Kubernetes, Docker, ACR, VNet, NSG, Application Gateway, WAF, Key Vault, Azure Storage, Azure Monitor, Log Analytics, Git, GitHub
